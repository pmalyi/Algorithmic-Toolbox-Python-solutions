## Дискретний рюкзак з масами. Кожна річ в єдиному екземплярі
### [Умова](https://basecamp.eolymp.com/uk/problems/4832)  

#### Розглянемо приклад:  
$s$ = 10 - вмістимість рюкзака,  
$n$ = 5 - кількість предметів,   
$m$ = {6, 5, 5, 3, 1} - маси предметів  
$c$ = {10, 8, 8, 2, 3} - вартості предметів

Очевидна «жадібна» стратегія взяти найдорожчий предмет, на який вистачає вмістимості 
рюкзака, і повторно перевірити, а чи залишилося місце на ще один предмет не матиме успіху.  
При наведеному вище наборі речей і рюкзаку місткістю 10 «жадібний» алгоритм вибирає три
речі: 
1. вартістю 10, вагою 6;
2. вартістю 3, вагою 1;
3. вартістю 2, вагою 3.  

загальною вартістю 15.   

Однак, оптимальне рішення — взяти два предмети вартість 8 і вагою 5. Тоді загальна вартість 
буде - 16, що краще, ніж 15.  

 #### Формулювання підзадачі
Припустимо, що нам вдалося сформувати набір предметів, загальна вага яких не перевищує $s$ 
і сумарна вартість предметів - максимальна.  
Введемо наступні позначення $dp[n][s]$ - кінцева сумарна максимальна вартість предметів 
(після того як ми перебрали всі предмети),  
$dp[i][j]$ — це максимальна вартість, яку можна отримати, використовуючи лише перші $i$ 
предметів покладених у рюкзак, що має максимальну вагу $j$. Тобто $i$ = 0, 1, 2, ... , $n$;
$j$ = 0, 1, 2, ... , $s$.  

#### Створення DP-таблиці (матриці)
Нам знадобиться двовимірна таблиця (матриця) dp розміром (n+1) x (s+1), де:
n — кількість предметів.
s — максимальна вага рюкзака.
Ми додаємо +1 до розмірів, щоб зручно працювати з індексами від 0 ($dp[0][0]$ означає "немає предметів" або 
"нульова вага").
Рядки i (від 0 до n) відповідатимуть кількості розглянутих предметів.
Стовпці j (від 0 до s) відповідатимуть поточній вазі рюкзака.
Отже, $dp[i][j]$ зберігатиме відповідь на нашу підзадачу. Кінцева відповідь (максимальна вартість) буде знаходитись 
в комірці $dp[n][s]$. 

#### Рекурентне співвідношення (динамічна функція)
Тепер найважливіша частина — як обчислити значення для кожної комірки $dp[i][j]$. Ми заповнюватимемо таблицю рядок за 
рядком, стовпець за стовпцем.
Розглядаючи $i$-й предмет (з вагою $m_i$ та вартістю $c_i$), ми маємо два варіанти для рюкзака з місткістю $j$:  
**Випадок 1**: Вага $i$-го предмета більша за поточну місткість рюкзака ($m_i$ > $j$).  
У цьому випадку ми просто не можемо покласти $i$-й предмет у рюкзак. Тому максимальна вартість, яку ми можемо 
отримати з першими $i$ предметами, буде такою ж, як і максимальна вартість, яку ми могли отримати з першими $i-1$ 
предметами при тій самій місткості $j$.  
$dp[i][j] = dp[i-1][j]$.  
**Випадок 2**: $i$-й предмет вміщується в рюкзак ($m_i <= j$)
Тут у нас є вибір:  
- *Варіант А*: Не брати $i$-й предмет, бо якщо його взяти, то сумарна маса предметів буде перевищувати $j$ - 
поточну вмістимість рюкзака.  
Тоді вартість буде такою ж, як і у випадку з $i-1$ предметами: $dp[i-1][j]$.   
- *Варіант Б*: Взяти $i$-й предмет (сумарна маса предметів не буде перевищувати $j$).  
Якщо ми його беремо, він приносить нам вартість $c_i$. Але він також займає вагу $m_i$. Отже, решта предметів 
(з перших $i-1$) повинна поміститись у рюкзак з вагою, що залишилась: $j - m_i$. Максимальна вартість, яку можна 
було отримати з перших $i-1$ предметів у рюкзаку місткістю $j - m_i$, зберігається в $dp[i-1][j - m_i]$. 
Таким чином, загальна вартість цього варіанту: $c_i + dp[i-1][j - m_i]$.   

Очевидно, що ми обираємо той варіант, який дає більшу вартість.   

$dp[i][j] = max(dp[i-1][j], c_i + dp[i-1][j - m_i])$ - це і є рекурентне співвідношення або динамічна функція.

#### Пошук предметів (Backtracking)
Після заповнення всієї таблиці $dp$ комірка $dp[n][s]$ буде містити максимальну можливу вартість. Але нам потрібні 
номери самих предметів. Для цього потрібно пройти по таблиці у зворотному напрямку, починаючи з $dp[n][s]$, 
і відновити наш вибір на кожному кроці.
Починаємо з $i = n$ та $j = s$.  
Перевіряємо, як було отримано значення $dp[i][j]$:  
Якщо $dp[i][j]$ дорівнює $dp[i-1][j]$, це означає, що $i$-й предмет не був взятий. У цьому випадку ми просто 
переходимо до попереднього рядка: $i = i - 1$.  
Якщо $dp[i][j]$ не дорівнює $dp[i-1][j]$, це означає, що $i$-й предмет був взятий. Ми додаємо його номер до нашого 
списку результатів. Оскільки ми взяли цей предмет, нам потрібно "звільнити" його вагу з рюкзака, тому ми переходимо
до $j = j - m_i$. І, звичайно, переходимо до попереднього предмета: $i = i - 1$.  
Повторюємо цей процес, доки $i$ не стане рівним 0.  
Оскільки ми рухалися у зворотному порядку, список предметів, які ми зібрали, буде в оберненому порядку. 
Тому перед виведенням його потрібно розвернути.

```python
def knapsack(s, m, c):
    n = len(m)
    # Ініціалізація DP-таблиці
    # dp[i][j] буде зберігати максимальну вартість для перших i предметів з вагою рюкзака j
    dp = [[0] * (s + 1) for _ in range(n + 1)] # Створюємо матрицю розміру (n+1)x(s+1) 
                                            # та заповнюємо її нулями

    # Динамічне програмування для знаходження максимальної вартості
    # Заповнення dp-таблиці
    # Ітеруємо по предметах (від 1 до n)
    for i in range(1, n + 1):
        # Оскільки масиви m та c мають 0-індексацію, звертаємось до m[i - 1] та c[i - 1]
        weight = m[i - 1] # Вага поточного i-го предмета
        value = c[i - 1]  # Вартість поточного i-го предмета

        # Ітеруємо по можливій вазі рюкзака (від 1 до s)
        for j in range(s + 1):
            # Якщо поточний предмет важчий за місткість рюкзака j,
            # ми не можемо його взяти.
            if weight > j:
                dp[i][j] = dp[i - 1][j]
            else:
                # В іншому випадку у нас є вибір:
                # 1. Не брати предмет: вартість буде dp[i - 1][j]
                # 2. Взяти предмет: вартість буде value + dp[i - 1][j - weight]
                # Обираємо максимум з двох варіантів
                dp[i][j] = max(dp[i - 1][j], value + dp[i - 1][j - weight])

    # Відновлення набору вибраних предметів (Backtracking)
    selected_items = []
    current_weight = s # Починаємо з кінця таблиці
    for i in range(n, 0, -1):
        # Якщо вартість у dp[i][current_weight] відрізняється від dp[i - 1][current_weight],
        # це означає, що i-й предмет був включений до оптимального набору.
        if dp[i][current_weight] != dp[i - 1][current_weight]:
            selected_items.append(i)  # Додаємо номер предмета (1-based index)
            current_weight -= m[i - 1] # Зменшуємо вагу рюкзака на вагу взятого предмета

    selected_items.reverse()  # Список предметів отримано в зворотному порядку, тому розвертаємо його
    return selected_items

# Зчитування вхідних даних
s = int(input())
m = list(map(int, input().split()))
c = list(map(int, input().split()))

# Обчислення та виведення результату
result = knapsack(s, m, c)
print(" ".join(map(str, result)))
```
