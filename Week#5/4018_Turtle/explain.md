Ця задача — класичний приклад для вивчення **динамічного програмування (ДП)**. Вона вчить нас тому, як розбивати складну задачу на прості підзадачі.

### ASCII-схема накопиченої шкоди (DP-таблиця)

Кожне число в квадратних дужках `[ ]` — це мінімальна шкода, яку черепашка отримала, щоб дістатися до цієї точки. Стрілки показують, звідки прийшов оптимальний (мінімальний) шлях.

```text
      (START)
         |
         v
      [ 5 ]  --->  [ 14 ]  --->  [ 18 ]  --->  [ 21 ]
        |            |             |             |
        v            v             v             v
      [ 8 ]  --->  [ 9  ]  --->  [ 15 ]  --->  [ 24 ]
        |            |             |             |
        v            v             v             v
      [ 16 ] --->  [ 15 ]  --->  [ 23 ]  --->  [ 35 ]
                                              (FINISH)

```

---

### Покрокове пояснення (як ми рахували):

1. **Перший рядок:** Черепашка може йти тільки вправо.
* (0,0): **5**
* (0,1): 5 + 9 = **14**
* (0,2): 14 + 4 = **18**
* (0,3): 18 + 3 = **21**


2. **Перший стовпчик:** Черепашка може йти тільки вниз.
* (1,0): 5 + 3 = **8**
* (2,0): 8 + 8 = **16**


3. **Клітинка (1,1):** Вибираємо мінімум між зверху (14) та зліва (8).
* $\min(14, 8) + 1 = 8 + 1 =$ **9**. (Прийшли зліва)


4. **Клітинка (2,1):** Вибираємо мінімум між зверху (9) та зліва (16).
* $\min(9, 16) + 6 = 9 + 6 =$ **15**. (Прийшли зверху)



### Оптимальний шлях черепашки:

Слідуючи за "найменшими" цифрами від кінця до початку, ми отримуємо такий маршрут:
**Вниз (D) -> Вправо (R) -> Вниз (D) -> Вправо (R) -> Вправо (R)**.

* **Шлях по клітинках:** 5 -> 3 -> 1 -> 6 -> 8 -> 12
* **Сума:** 5 + 3 + 1 + 6 + 8 + 12 = **35**

---

### 1. Принцип динамічного програмування (ДП) на цьому прикладі

Уявіть, що черепашка вже стоїть у якійсь клітинці $(i, j)$. Як вона могла туди потрапити? Оскільки вона рухається лише **вправо** або **вниз**, вона могла прийти або з клітинки зверху $(i-1, j)$, або з клітинки зліва $(i, j-1)$.

**Основна ідея:** щоб знайти найменшу шкоду для поточної клітинки, нам потрібно знати найменшу шкоду для тих клітинок, з яких ми могли прийти, і обрати з них мінімальну.

---

### 2. Спосіб №1: Класичне ДП з використанням додаткової таблиці

Це найбільш зрозумілий спосіб для учнів. Ми створюємо ще одну таблицю `dp` такого ж розміру, де в кожній клітинці будемо зберігати "мінімальну шкоду на шляху від старту до цієї точки".

#### Алгоритм:

1. **Базовий випадок:** У стартовій клітинці `dp[0][0]` шкода дорівнює значенню самої клітинки.
2. **Перший рядок:** Черепашка може потрапити сюди тільки рухаючись вправо. Отже, шкода в `dp[0][j]` — це сума всіх попередніх клітинок у рядку.
3. **Перший стовпчик:** Сюди можна потрапити тільки рухаючись вниз. Шкода в `dp[i][0]` — сума всіх попередніх клітинок у стовпчику.
4. **Решта клітинок:** Для кожної клітинки $(i, j)$ формула буде такою:

$$dp[i][j] = acid[i][j] + \min(dp[i-1][j], dp[i][j-1])$$



#### Код на Python:

```python
def min_acid_path():
    # Зчитуємо розміри таблиці
    n, m = map(int, input().split())
    
    # Зчитуємо таблицю з кислотою
    acid = []
    for _ in range(n):
        acid.append(list(map(int, input().split())))
        
    # Створюємо таблицю для результатів (DP-таблиця)
    dp = [[0] * m for _ in range(n)]
    
    # Крок 1: Початкова точка
    dp[0][0] = acid[0][0]
    
    # Крок 2: Заповнюємо перший рядок (тільки вправо)
    for j in range(1, m):
        dp[0][j] = dp[0][j-1] + acid[0][j]
        
    # Крок 3: Заповнюємо перший стовпчик (тільки вниз)
    for i in range(1, n):
        dp[i][0] = dp[i-1][0] + acid[i][0]
        
    # Крок 4: Заповнюємо решту таблиці за формулою
    for i in range(1, n):
        for j in range(1, m):
            # Обираємо мінімум між "прийти зверху" або "прийти зліва"
            dp[i][j] = acid[i][j] + min(dp[i-1][j], dp[i][j-1])
            
    # Відповідь знаходиться в нижньому правому куті
    print(dp[n-1][m-1])

min_acid_path()

```

### 3. Спосіб №2: Оптимізація пам'яті (In-place DP)

Якщо нам не потрібно зберігати початкові дані, ми можемо змінювати саму таблицю `acid`. Це економить пам'ять, оскільки нам не потрібен масив `dp`.

```python
# Замість створення нової таблиці, ми просто перезаписуємо вхідну
for i in range(n):
    for j in range(m):
        if i == 0 and j == 0:
            continue
        elif i == 0: # перший рядок
            acid[i][j] += acid[i][j-1]
        elif j == 0: # перший стовпчик
            acid[i][j] += acid[i-1][j]
        else:
            acid[i][j] += min(acid[i-1][j], acid[i][j-1])
print(acid[n-1][m-1])

```

### 4. Чому це працює? (Резюме для учнів)

Ця задача демонструє три кити ДП:

1. **Підзадачі:** Щоб дійти до кінця, треба спочатку оптимально дійти до сусідніх клітинок.
2. **Відсутність післядії:** Нам не важливо, *як саме* ми прийшли в клітинку зверху, нам важливо лише те, яка там *мінімальна сума*.
3. **Перекриття підзадач:** Ми рахуємо значення для кожної клітинки лише один раз і зберігаємо його, щоб використовувати надалі (це називається мемоїзація).

---

Це чудове розширення задачі! Для того, щоб вивести не тільки суму, а й сам шлях, нам потрібно виконати **"зворотний хід"** (backtracking).

Після того, як ми заповнили таблицю `dp`, ми знаємо мінімальну вартість у кожній точці. Тепер ми починаємо з фінішу (нижній правий кут) і дивимося: *"Звідки було вигідніше прийти — зверху чи зліва?"*.

---

### Модифіковане рішення на Python

```python
def min_acid_path_with_route():
    import sys
    
    # Зчитуємо розміри
    input_data = sys.stdin.read().split()
    if not input_data: return
    n, m = int(input_data[0]), int(input_data[1])
    
    # Формуємо таблицю кислоти
    acid = []
    idx = 2
    for i in range(n):
        acid.append([int(x) for x in input_data[idx : idx + m]])
        idx += m
        
    # Створюємо DP-таблицю
    dp = [[0] * m for _ in range(n)]
    
    # Заповнюємо DP-таблицю (прямий хід)
    for i in range(n):
        for j in range(m):
            if i == 0 and j == 0:
                dp[i][j] = acid[i][j]
            elif i == 0:
                dp[i][j] = dp[i][j-1] + acid[i][j]
            elif j == 0:
                dp[i][j] = dp[i-1][j] + acid[i][j]
            else:
                dp[i][j] = acid[i][j] + min(dp[i-1][j], dp[i][j-1])
                
    # Виводимо мінімальну шкоду
    print(f"Мінімальна шкода: {dp[n-1][m-1]}")
    
    # Відновлення шляху (зворотний хід)
    path = []
    curr_i, curr_j = n - 1, m - 1
    
    while curr_i > 0 or curr_j > 0:
        if curr_i == 0: # Ми в першому рядку, шлях тільки зліва
            path.append("R")
            curr_j -= 1
        elif curr_j == 0: # Ми в першому стовпчику, шлях тільки зверху
            path.append("D")
            curr_i -= 1
        else:
            # Порівнюємо значення в сусідніх клітинках DP-таблиці
            if dp[curr_i - 1][curr_j] < dp[curr_i][curr_j - 1]:
                path.append("D")
                curr_i -= 1
            else:
                path.append("R")
                curr_j -= 1
                
    # Оскільки ми йшли з кінця в початок, список треба розвернути
    print("Шлях:", "".join(path[::-1]))

min_acid_path_with_route()

```

### Як працює зворотний хід (Backtracking)?

Уявіть, що ви стоїте на фініші. Подивіться на клітинку зліва та клітинку зверху в таблиці `dp`.

* Якщо число зверху менше — значить, найдешевший шлях до фінішу прийшов саме звідти. Ви робите крок назад (вгору) і записуєте "D" (бо звідти ви йшли вниз).
* Якщо числа рівні — можна обрати будь-який шлях.

### Варіанти оптимізації та вправи для учнів:

2. **Діагональний рух:** Що, якщо черепашка зможе ходити ще й по діагоналі вправо-вниз? Як зміниться функція `min()` і відновлення шляху?
