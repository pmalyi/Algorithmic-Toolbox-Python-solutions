# Відстань редагування (Алгоритм Вагнера-Фішера)

## 1. Постановка задачі

**Відстань Левенштейна (Edit Distance)** — це метрика схожості між двома рядками, що визначається як мінімальна кількість операцій, необхідних для перетворення одного рядка в інший.

**Дозволені операції:**

1. **Вставка (Insert):** додати символ.
2. **Видалення (Delete):** прибрати символ.
3. **Заміна (Replace):** змінити один символ на інший.

---

## 2. Чому не підходить рекурсія?

Наївний рекурсивний підхід має експоненціальну складність $O(3^{n+m})$. Багато підзадач обчислюються повторно. Наприклад, для перетворення `horse` в `ros` ми будемо багато разів перевіряти відстань між `orse` та `os`.

---

## 3. Динамічне програмування (ДП)

Ми розв'яжемо цю задачу за допомогою таблиці розміром $(n+1) \times (m+1)$, де $n$ та $m$ — довжини рядків.
Кожна клітинка `dp[i][j]` означає: *«Мінімальна кількість операцій для перетворення підрядка word1[0...i] у word2[0...j]»*.

### Базові випадки (Межі таблиці):

* Якщо `word2` порожній ($j=0$), нам потрібно видалити всі символи з `word1`. Отже, `dp[i][0] = i`.
* Якщо `word1` порожній ($i=0$), нам потрібно вставити всі символи з `word2`. Отже, `dp[0][j] = j`.

### Перехідне рівняння (Основна логіка):

Для кожної клітинки $(i, j)$ ми дивимось на поточні символи `word1[i-1]` та `word2[j-1]`:

1. **Якщо символи однакові:** Операція не потрібна.

$$dp[i][j] = dp[i-1][j-1]$$


2. **Якщо символи різні:** Ми обираємо мінімум з трьох попередніх станів + 1 операція:
* `dp[i-1][j]` + 1 (Видалення)
* `dp[i][j-1]` + 1 (Вставка)
* `dp[i-1][j-1]` + 1 (Заміна)



---

## 4. Візуалізація (Приклад horse -> ros)

|  | # | r | o | s |
| --- | --- | --- | --- | --- |
| **#** | 0 | 1 | 2 | 3 |
| **h** | 1 | 1 | 2 | 3 |
| **o** | 2 | 2 | 1 | 2 |
| **r** | 3 | 2 | 2 | 2 |
| **s** | 4 | 3 | 3 | 2 |
| **e** | 5 | 4 | 4 | **3** |

*Результат: 3*

---

## 5. Реалізація на Python

```python
def minDistance(word1: str, word2: str) -> int:
    n = len(word1)
    m = len(word2)
    
    # Створюємо DP-таблицю (n+1) x (m+1)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    
    # Заповнюємо базові випадки
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j
        
    # Основний цикл заповнення
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if word1[i-1] == word2[j-1]:
                # Символи збігаються - копіюємо діагональне значення
                dp[i][j] = dp[i-1][j-1]
            else:
                # Символи різні - обираємо мінімум + 1
                dp[i][j] = 1 + min(
                    dp[i-1][j],    # Видалення
                    dp[i][j-1],    # Вставка
                    dp[i-1][j-1]   # Заміна
                )
    
    return dp[n][m]

# Тест
print(f"Результат для 'horse' та 'ros': {minDistance('horse', 'ros')}") # 3

```

## 6. Аналіз складності

* **Часова складність:** $O(n \times m)$ — ми проходимо крізь кожну клітинку матриці один раз.
* **Просторова складність:** $O(n \times m)$ для зберігання матриці.
* *Примітка:* Просторову складність можна оптимізувати до $O(\min(n, m))$, оскільки для обчислення поточного рядка нам потрібен лише попередній.

---

### 1. Формалізація задачі через префікси

Для розв’язання задачі динамічним програмуванням ми вводимо поняття **стан**. Нехай $word1 = A$, $word2 = B$.
Стан $D(i, j)$ — це мінімальна відстань редагування між префіксом рядка $A$ довжиною $i$ та префіксом рядка $B$ довжиною $j$.

**Цільовий стан:** $D(n, m)$, де $n = |A|, m = |B|$.

### 2. Логічне обґрунтування переходів (Recurrence Relation)

При обчисленні $D(i, j)$ ми розглядаємо останню операцію, яка привела нас до цього стану:

1. **Заміна (або співпадіння):** ми перетворили $A[1 \dots i-1]$ на $B[1 \dots j-1]$, а потім розглядаємо останні символи $A[i]$ та $B[j]$.
* Якщо $A[i] = B[j]$, вартість операції $cost = 0$.
* Якщо $A[i] \neq B[j]$, вартість операції $cost = 1$.
* Формула: $D(i-1, j-1) + cost$.


2. **Видалення:** ми вже перетворили $A[1 \dots i-1]$ на $B[1 \dots j]$, тому символ $A[i]$ просто видаляється.
* Формула: $D(i-1, j) + 1$.


3. **Вставка:** ми перетворили $A[1 \dots i]$ на $B[1 \dots j-1]$, тому символ $B[j]$ потрібно вставити в кінець.
* Формула: $D(i, j-1) + 1$.

---

### 3. Оптимізація пам'яті (Memory Optimization)

Важливий аспект, який часто розглядається на співбесідах та в олімпіадному програмуванні: для обчислення поточного рядка матриці $D[i]$ нам потрібен лише попередній рядок $D[i-1]$.

Це дозволяє зменшити просторову складність з $O(N \times M)$ до **$O(M)$**.

**Реалізація з оптимізацією пам'яті:**

```python
def min_distance_optimized(word1: str, word2: str) -> int:
    n, m = len(word1), len(word2)
    if n < m: return min_distance_optimized(word2, word1) # Оптимізація: m - менший рядок
    
    prev = list(range(m + 1))
    curr = [0] * (m + 1)
    
    for i in range(1, n + 1):
        curr[0] = i
        for j in range(1, m + 1):
            cost = 0 if word1[i-1] == word2[j-1] else 1
            curr[j] = min(curr[j-1] + 1,      # Вставка
                          prev[j] + 1,        # Видалення
                          prev[j-1] + cost)   # Заміна/Співпадіння
        prev[:] = curr
    return prev[m]

```

### 4. Відновлення послідовності операцій (Backtracking)

Щоб не просто отримати число, а зрозуміти, які саме зміни відбулися, ми виконуємо зворотний хід від $D(n, m)$ до $D(0, 0)$. На кожному кроці ми перевіряємо, з якого сусіда (зліва, зверху чи по діагоналі) ми отримали мінімальне значення.

* **Крок по діагоналі:** якщо значення змінилося — **Replace**, якщо ні — **Keep**.
* **Крок вгору:** **Delete** (видалення з першого рядка).
* **Крок вліво:** **Insert** (додавання символу з другого рядка).
